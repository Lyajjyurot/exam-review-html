# 内容模型（review_content.json）

`build_review_html.py` 的输入是一个 JSON。字段结构固定，字段名不可改名。

## 顶层

```json
{
  "meta": {
    "title": "期末复习冲刺包",          // 浏览器标题 & 左上角标题
    "subtitle": "知识要点 · 速背速记 · 模拟题解析",
    "generated_at": "2026-09-11",       // 可选，显示在页脚
    "note": "依据《xxx》提纲生成，仅供个人复习" // 可选，页脚说明
  },
  "subjects": [ /* 见下，每个科目一个顶部切换按钮 */ ]
}
```

## subject

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 否 | 唯一标识，缺省自动生成；用于 localStorage 存档键 |
| `name` | string | 是 | 科目名，显示在切换按钮与页面大标题 |
| `short` | string | 否 | 短名，缺省取 name 前 4 字 |
| `icon` | string | 否 | 缺省取 name 首字（当前模板未使用，可忽略） |
| `color` | string | 否 | 主色十六进制，缺省按序自动分配（8 色循环） |
| `overview` | string | 否 | 一句话复习策略，显示在 hero 区；第一句会被放大成标题 |
| `stats` | array | 否 | 预留，当前模板未渲染 |
| `key_points` | array | 否 | 知识要点（按章节分组） |
| `memorize` | array | 否 | 速背速记卡 |
| `quiz` | array | 否 | 模拟题 |
| `pitfalls` | array | 否 | 易错点 / 命题陷阱 |
| `checklist` | array of string | 否 | 考前自测清单 |

## key_points[]（章节）

```json
{
  "chapter": "第三章 微分中值定理与导数应用",
  "weight": "高频考点",              // 含「高频/重点/必考/核心」时标签变红
  "items": [
    {
      "term": "罗尔定理",                       // 要点名称
      "body": "若 f(x) 在 [a,b] 连续、(a,b) 可导，且 f(a)=f(b)，则至少存在一点 ξ∈(a,b) 使 f'(ξ)=0。",
      "note": "三个条件缺一不可；题目常通过「去掉端点相等」或「区间内不可导」设置陷阱。",
      "level": "core",                          // core=核心必背 / key=重点掌握 / basic=一般了解
      "tags": ["必背", "易错", "定理条件"]      // 可选
    }
  ]
}
```

## memorize[]

```json
{
  "type": "口诀",              // 口诀 / 对比表 / 公式卡 / 数字归纳 / 流程图 / 清单
  "title": "中值定理三兄弟",
  "content": "<ul><li>罗尔：两端等高</li><li>拉格朗日：弦的斜率</li></ul>",
  "mask": true                 // true 时卡片默认打码，点击「显示内容」自测
}
```

- `content` 字段**按原始 HTML 渲染**，允许 `<table>` / `<ul>` / `<code>` / `<span class="formula">`，这是唯一允许写 HTML 的字段。
- 其余所有字段先转义再渲染，支持三种极简标记：`**加粗**`、`==高亮==`、`` `代码` ``，换行自动转 `<br>`。
- 公式建议写成 `<span class="formula">f'(ξ)=0</span>`，会居中突出显示。

## quiz[]

```json
{
  "type": "单选",               // 单选/多选/判断/填空/名词解释/简答/计算/论述/案例分析
  "stem": "下列关于罗尔定理条件的表述，正确的是（　）",
  "options": ["在 [a,b] 上可导", "在 (a,b) 内连续且 f(a)=f(b)", "在 [a,b] 连续、(a,b) 可导且 f(a)=f(b)", "以上都不对"],
  "answer": "C",                // 可写字母 "C"、字母组 "ABD"、或选项全文
  "analysis": "A 错在把闭区间可导当条件……；B 错在连续性区间写反；C 三个条件齐备，正确。",
  "level": "中",                // 易 / 中 / 难
  "source": "第三章 · 罗尔定理"  // 回扣考点，解析区会提示回去背哪里
}
```

判分规则（脚本已实现，无需干预）：
- 单选题 `answer` 写成 A/B/C/D 或选项全文均可；脚本自动归一化比对。
- 多选题 `answer` 写 `"ABD"` 或 `["A","B","D"]` 语义等价的文本；选中集合与正确集合完全相等才判对。
- 判断题建议 `options: ["正确","错误"]`，`answer: "正确"`。
- 填空 / 名词解释 / 简答 / 计算：`options` 留空数组，答案与解析放在 `answer` / `analysis`，页面显示「显示参考答案」按钮。

## pitfalls[] 与 checklist[]

```json
"pitfalls": [
  { "title": "把「驻点」与「极值点」混为一谈", "detail": "驻点只要求 f'(x)=0，极值点还需两侧单调性改变。" }
],
"checklist": [
  "能独立默写出三个中值定理的条件与结论",
  "10 分钟内做完一套极限计算不翻书"
]
```

`pitfalls` 的元素也可以直接写字符串（脚本会自动转成 `{title, detail:""}`）。

## 排版约定

- 全中文标点，题干中的填空位用全角括号 `（　）` 或 `______`。
- 要点 `body` 控制在 2–4 句；`note`（批注）控制在 1–3 句，只写提纲里没有的东西。
- 一个科目的 `quiz` 建议 10–25 题；低于 5 题构建脚本会告警。
- 不要在任何字段里出现未转义的 `</script>`。
