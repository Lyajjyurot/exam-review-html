# 批注 · 速记 · 命题 方法论

这份文档决定生成内容的「含金量」。抽取完原文只是原材料，下面的规则决定它值不值得背。

## 一、三步处理原文

1. **分块**：按原文的章节标题/编号切块，每一块对应 `key_points` 的一个 `chapter`。原文没有标题时，按语义主题自行归纳并命名章节（如「第二章 · 排序与查找」）。
2. **定级**：给每个要点打 `level`。
   - `core`（核心必背）：定义、定理、公式、必考概念、老师反复强调的条目 —— 控制在要点总数的 20%–30%。
   - `key`（重点掌握）：需要理解并会用的内容 —— 50%–60%。
   - `basic`（一般了解）：背景、拓展、举例 —— 其余。
3. **批注**：`note` 字段不是复述 `body`。只写这四类信息，写不出就留空：
   - **易错**：别人常在这里错什么（"闭区间连续、开区间可导，两者区间写反是最常见的丢分点"）。
   - **条件**：成立的前提、适用范围、例外（"仅在 X 为独立同分布时成立"）。
   - **关联**：与另一个考点的关系（"是拉格朗日定理 f(a)=f(b) 时的特例"）。
   - **考法**：命题形式（"常以判断题形式考查条件缺失"）。

反面示例（禁止）："本知识点很重要，需要重点掌握。" —— 零信息量。

## 二、速背速记的六种写法

每个科目至少 3 张卡，混合使用不同写法，不要全是罗列。

| 类型 | 适用内容 | 写法要点 |
|---|---|---|
| 口诀 | 并列条目、步骤流程 | 押韵、缩字、串成一句荒诞的话；控制在 20 字内，并附"每字对应什么" |
| 对比表 | 易混淆概念组 | 用 `<table>`，行=概念，列=判别维度；单元格只写关键词 |
| 公式卡 | 公式、定理 | `<span class="formula">` 突出公式本体，下面一句写"何时用"，一句写"符号含义" |
| 数字归纳 | 带数字的知识点 | "三要素 / 四步骤 / 五特性"，编号列出，配合 `mask: true` 做自测 |
| 流程清单 | 解题步骤 | 有序列表，每步一个动词开头（"先…再…最后…"） |
| 反例卡 | 陷阱类 | 标题写"❌ 常见错误说法"，内容写错误说法→为什么错→正确说法 |

`mask: true` 只给"适合闭卷自测"的卡片（口诀、数字归纳、流程），对比表和公式卡通常不需要遮罩。

## 三、命题方法

### 题型配比（无特殊说明时按此执行）
- 单选 40%、多选/判断 20%、填空/名词解释 20%、简答/计算/论述 20%。
- 理工科可加大计算题比重，文科可加大简答与论述比重，以科目性质为准。

### 干扰项设计（决定题目质量的关键）
从原文中取材，不要用"以上都对/都不对"凑数：
1. **偷换条件**：把 `[a,b]` 换成 `(a,b)`，把"充分"换成"必要"。
2. **张冠李戴**：把 A 概念的定义安到 B 概念上。
3. **以偏概全**：把特例说成通例。
4. **因果倒置 / 时序颠倒**。
5. **形近混淆**：同章节内另一个真实存在的概念。

### 解析三段式
每道题的 `analysis` 建议按此结构写，短题可合并：
1. **考点定位**：一句话点明考的是什么。
2. **逐项说明**：正确项为什么对；错误项为什么错（至少逐条说明每个干扰项的错因）。
3. **易错提醒**：一句话提醒下次如何避开。

示例：
> 考点：罗尔定理的三个条件。A 错在把「闭区间可导」当作条件，罗尔定理只要求在开区间内可导；B 将连续性误写在开区间，正确应为闭区间连续；C 三个条件齐备，正确；D 显然不成立。提醒：三个条件的区间开闭是最高频的命题陷阱，背诵时务必连同区间一起记。

### 覆盖原则
- 每章至少 2 道题，`core` 级要点至少被 1 道题覆盖。
- `source` 字段必须回指到具体章节/要点名，形成"做题→回扣→再背"的闭环。

## 四、易错点与自测清单

- `pitfalls`：从命题过程中自然沉淀，5–10 条，写"错在哪 + 正确是什么"。
- `checklist`：可验证的动作，动词开头、能判断完成与否（"能默写出…" / "10 分钟内做完…"），5–8 条。

## 五、质量红线

- 每个要点的 `body` 必须忠于原文，不得杜撰原文没有的断言；`note` 中的补充应是公认常识或可直接从原文推出的结论。
- 题目答案必须唯一且无争议；多选题答案不少于 2 个。
- 不使用"显然""众所周知""不难看出"这类空话。
- 科目名直接用文件名或原文标题推断，不要自己另起一套命名。
